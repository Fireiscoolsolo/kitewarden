- Summary: ClaudeCodeBrowser is a Firefox MV2 WebExtension plus a local Python MCP server that exposes 48 `browser_*` tools to Claude Code. Claude Code talks to a stdio wrapper, which calls an authenticated HTTP API on 127.0.0.1:8765; the server queues each command, a native-messaging host polls and relays it, and the extension runs it through tabs APIs and a content script. A headless Playwright backend (separate browser) and a server-side safety guard (URL rules, protected-site confirmation, rate limit, audit log) sit alongside.

## Architecture

- Claude Code to MCP server: stdio JSON-RPC written by hand (no MCP SDK import), protocol 2024-11-05, capabilities limited to tools; no prompts, resources or server instructions ([stdio_wrapper.py#L139-L154](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/mcp-server/stdio_wrapper.py#L139-L154), [server.py#L23-L49](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/mcp-server/server.py#L23-L49)). Unknown methods, including ping, return -32601 ([stdio_wrapper.py#L217-L237](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/mcp-server/stdio_wrapper.py#L217-L237)).
- stdio wrapper to HTTP server: calls http://HOST:8765 with X-API-Key read from ~/.claudecodebrowser/api_token. If /health fails it starts server.py as a detached child ([stdio_wrapper.py#L21-L23](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/mcp-server/stdio_wrapper.py#L21-L23), [stdio_wrapper.py#L31-L41](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/mcp-server/stdio_wrapper.py#L31-L41), [stdio_wrapper.py#L48-L89](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/mcp-server/stdio_wrapper.py#L48-L89), [stdio_wrapper.py#L102-L115](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/mcp-server/stdio_wrapper.py#L102-L115)).
- HTTP server: stdlib ThreadingHTTPServer bound to CLAUDE_BROWSER_HOST (default 127.0.0.1) and CLAUDE_BROWSER_HTTP_PORT (default 8765). GET: /health (no token), /mcp/tools, /screenshots, /browser/poll. POST: /mcp/call, /browser/command, /browser/response. Other routes 404 ([server.py#L101-L104](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/mcp-server/server.py#L101-L104), [server.py#L885-L1007](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/mcp-server/server.py#L885-L1007), [server.py#L1472-L1476](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/mcp-server/server.py#L1472-L1476)).
- Per tool call: safety guard first, then three server-side tools (browser_safety_status, browser_run_workflow, browser_audit_page), then the action map to a browser action ([server.py#L1009-L1121](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/mcp-server/server.py#L1009-L1121)).
- Transport choice in _dispatch_action: a connected WebSocket client if any, else headless Playwright if CLAUDE_BROWSER_HEADLESS=1, else the HTTP queue polled by the native host. Timeouts: 30 s default, 90 s approval, 200 s captcha ([server.py#L1123-L1245](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/mcp-server/server.py#L1123-L1245)).
- WebSocket server on CLAUDE_BROWSER_WS_PORT (default 8766): first frame must carry the token; no client exists in this repository ([server.py#L1479-L1526](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/mcp-server/server.py#L1479-L1526), [server.py#L1529-L1540](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/mcp-server/server.py#L1529-L1540)).
- Native host (claudecodebrowser_host.py): started by Firefox through connectNative. Polls GET /browser/poll every 0.5 s and relays each command as a native-messaging message; relays extension responses back by POST /browser/response. Starts and health-checks the server ([claudecodebrowser_host.py#L90-L120](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/native-host/claudecodebrowser_host.py#L90-L120), [claudecodebrowser_host.py#L388-L423](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/native-host/claudecodebrowser_host.py#L388-L423), [claudecodebrowser_host.py#L471-L501](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/native-host/claudecodebrowser_host.py#L471-L501), [claudecodebrowser_host.py#L504-L549](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/native-host/claudecodebrowser_host.py#L504-L549)).
- Extension background: persistent MV2 background page that calls connectNative("claudecodebrowser") and dispatches commands in handleCommand ([manifest.json#L20-L23](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/extension/manifest.json#L20-L23), [background.js#L10-L11](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/extension/background.js#L10-L11), [background.js#L40-L45](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/extension/background.js#L40-L45), [background.js#L182-L316](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/extension/background.js#L182-L316)).
- Content script: runs in every frame at document_end in the isolated content-script world; performs DOM actions, network and console interception, and in-page banners ([manifest.json#L25-L33](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/extension/manifest.json#L25-L33), [content.js#L10-L15](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/extension/content.js#L10-L15), [content.js#L324-L400](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/extension/content.js#L324-L400)).
- Headless path: Playwright launches its own browser (firefox by default, or chromium or webkit) headless with a new context, separate from the user's profile ([headless_backend.py#L28-L34](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/mcp-server/headless_backend.py#L28-L34), [headless_backend.py#L59-L69](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/mcp-server/headless_backend.py#L59-L69)).
- Browser API family: WebExtension MV2 (manifest_version 2). No CDP, Marionette or WebDriver BiDi code is present. An experimental MV3 Chrome build is produced by a script ([manifest.json#L2-L3](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/extension/manifest.json#L2-L3), [build-chrome.sh#L42-L46](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/scripts/build-chrome.sh#L42-L46)).
- Sidebar or LLM UI: none. The only UI besides in-page banners is a toolbar popup ([manifest.json#L35-L43](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/extension/manifest.json#L35-L43), [popup.html#L9-L74](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/extension/popup/popup.html#L9-L74)).
- Installers and platforms: scripts/install.ps1 (Windows, HKCU registry), scripts/install.sh (Linux and macOS, with a Darwin launcher branch). Packaging: package-extension.sh and .ps1, publish-release.sh (bash only), build-chrome.sh (bash only), uninstall.sh (bash only) ([install.ps1#L92-L96](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/scripts/install.ps1#L92-L96), [install.sh#L25-L29](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/scripts/install.sh#L25-L29), [package-extension.ps1#L46-L64](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/scripts/package-extension.ps1#L46-L64), [publish-release.sh#L40-L58](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/scripts/publish-release.sh#L40-L58)).

## Firefox implementation notes

- Page-world script execution (browser_execute_script, browser_eval_chain, browser_wait_and_act, browser_inject_observer): the attended path uses tabs.executeScript with code, which runs in the extension's content-script context. Reaching page JavaScript needs a different injection route. Confirm against stable Firefox 160 APIs before design; not verified here.
- Network and console logging (browser_start_logging through browser_clear_logs, browser_wait_for_network_idle): fetch and XHR hooks run in the content-script world, which Firefox sandboxes; the code's own comments say window.fetch can be read-only. Page-origin traffic may not be captured. A different mechanism is needed for reliable capture.
- Full-page screenshot (browser_screenshot with full_page): captureVisibleTab captures only the visible area, and the code's full-page branch is broken. It needs scroll-and-stitch or another method.
- Screenshot of other tabs and focus changes (browser_screenshot, browser_screenshot_all_tabs, browser_focus_tab): the code switches the visible tab to capture it and restores it afterwards. A background tab capture approach would avoid visible focus changes; the design needs to decide whether this is acceptable.
- Human approval and captcha banners (browser_request_approval, browser_solve_captcha): these are injected into the page DOM and can be clicked by page script. Trusted decisions need extension-owned UI such as a sidebar or panel. Notifications (browser.notifications) and context menus work as native WebExtension APIs.
- Headless backend (CLAUDE_BROWSER_HEADLESS): it launches a separate browser instance with its own profile, so it does not satisfy the requirement to use the user's signed-in profile.
- Native messaging (connectNative, Windows HKCU registry, ~/.mozilla/native-messaging-hosts on Linux): the mechanism is a native WebExtension feature and fits. The stale-process kill and the Python dependency need to be replaced in a shipped design.
- Temporary add-on loading (about:debugging, documented in both installers) does not persist across Firefox restarts (README line 241). A signed .xpi (scripts/package-extension) is the persistent path; signing was not run here.
- MV2 manifest (manifest_version 2, persistent background): confirm MV2 support on stable Firefox 160 before reuse; not checked in this audit.
- The Chromium MV3 build (scripts/build-chrome.sh) is not a Firefox path and should not be reused as is.
- Popup and in-page DOM access: the toolbar popup is a native browser_action and fits. Clipboard copy from the popup uses navigator.clipboard ([popup.js#L63](https://github.com/nanogenomic/ClaudeCodeBrowser/blob/96a7fd398f080f30caf34ce4669bee354f1f297f/extension/popup/popup.js#L63)) and fits, but it copies unmasked password values, so a Firefox design should exclude them.
