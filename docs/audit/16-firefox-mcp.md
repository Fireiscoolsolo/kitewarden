- Summary: MCP for Firefox is a Manifest V2 Firefox WebExtension plus a Node.js stdio MCP server (`firefox-mcp`) that exposes one tool, `browser`, which runs line-based commands (navigate, click, type, snapshot, eval, screenshot, requests, dialogs) against tabs an agent selects or opens. The server reaches the extension through a per-user daemon bound to 127.0.0.1, and the extension only accepts it after the user pairs the daemon's key with a six-digit code and clicks Allow in the toolbar popup. There is no sidebar, no per-tab user grant, no audit log, and no resources, prompts or skills; those gaps are listed below.

## Firefox implementation notes

- Works on stable Firefox as written, with no change: tabs and webNavigation, scripting through tabs.executeScript into claimed frames, storage, the popup, WebCrypto pairing, synthetic mouse and key events with the default actions emulated in the content script, page-world hooks through exportFunction and wrappedJSObject, and tabs.captureTab screenshots ([tabs.ts#L156-L163](https://github.com/dh1011/firefox-mcp/blob/64212a5988eb3384a70ec1e6c88428e65d8ec39c/src/extension/background/tabs.ts#L156-L163), [hooks.ts#L211-L220](https://github.com/dh1011/firefox-mcp/blob/64212a5988eb3384a70ec1e6c88428e65d8ec39c/src/extension/content/hooks.ts#L211-L220), [page.ts#L357-L359](https://github.com/dh1011/firefox-mcp/blob/64212a5988eb3384a70ec1e6c88428e65d8ec39c/src/extension/background/page.ts#L357-L359)).
- Needs a different implementation for a stable-Firefox companion:
  1. The transport. The AI app, a Node stdio process, a localhost daemon and a token-plus-pairing WebSocket are all outside Firefox. A sidebar-based companion has no reason to start a separate Node process, so the transport layer ([daemon.ts#L37-L100](https://github.com/dh1011/firefox-mcp/blob/64212a5988eb3384a70ec1e6c88428e65d8ec39c/src/server/daemon.ts#L37-L100), [daemon-client.ts#L60-L110](https://github.com/dh1011/firefox-mcp/blob/64212a5988eb3384a70ec1e6c88428e65d8ec39c/src/server/daemon-client.ts#L60-L110)) must be replaced, not reused.

These need Manifest V2 blocking listeners ([tabs.ts#L282-L287](https://github.com/dh1011/firefox-mcp/blob/64212a5988eb3384a70ec1e6c88428e65d8ec39c/src/extension/background/tabs.ts#L282-L287), [manifest.json#L19-L21](https://github.com/dh1011/firefox-mcp/blob/64212a5988eb3384a70ec1e6c88428e65d8ec39c/src/extension/static/manifest.json#L19-L21)).
