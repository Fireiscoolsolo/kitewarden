- Summary: FoxMCP is a Python MCP server (FastMCP 3.x) and a Manifest V2 Firefox WebExtension that connects to it over a localhost WebSocket. The server registers 47 MCP tools that act on the user's running Firefox profiles (windows, tabs, containers, tab groups, history, bookmarks, navigation, page text and HTML, page-script execution, file upload into pages, screenshots, and request monitoring); every browser command is routed by profile_id. In-page script execution can be gated per tab and origin by an opt-in consent setting that is off by default.

## Architecture

- Hop 1, MCP client to server: two transports. Streamable HTTP served by uvicorn on the configured host, default port 3000 ([mcp_frontend.py#L86-L100](https://github.com/ThinkerYzu/foxmcp/blob/cc97d6ae90a9cd2a7bdeb9e38feaf9d29c395921/server/mcp_frontend.py#L86-L100), [mcp_frontend.py#L112-L143](https://github.com/ThinkerYzu/foxmcp/blob/cc97d6ae90a9cd2a7bdeb9e38feaf9d29c395921/server/mcp_frontend.py#L112-L143)), or stdio when started with --stdio ([server.py#L131-L134](https://github.com/ThinkerYzu/foxmcp/blob/cc97d6ae90a9cd2a7bdeb9e38feaf9d29c395921/server/server.py#L131-L134), [mcp_frontend.py#L198-L200](https://github.com/ThinkerYzu/foxmcp/blob/cc97d6ae90a9cd2a7bdeb9e38feaf9d29c395921/server/mcp_frontend.py#L198-L200)). Host is forced to localhost or 127.0.0.1 ([server.py#L198-L201](https://github.com/ThinkerYzu/foxmcp/blob/cc97d6ae90a9cd2a7bdeb9e38feaf9d29c395921/server/server.py#L198-L201)). When on, each tab and origin pair needs an approval in the popup, with a 60-second deadline and a per-tab, per-origin decision cache ([background.js#L384-L432](https://github.com/ThinkerYzu/foxmcp/blob/cc97d6ae90a9cd2a7bdeb9e38feaf9d29c395921/extension/background.js#L384-L432), [background.js#L434-L469](https://github.com/ThinkerYzu/foxmcp/blob/cc97d6ae90a9cd2a7bdeb9e38feaf9d29c395921/extension/background.js#L434-L469), [background.js#L524-L545](https://github.com/ThinkerYzu/foxmcp/blob/cc97d6ae90a9cd2a7bdeb9e38feaf9d29c395921/extension/background.js#L524-L545), [background.js#L476-L489](https://github.com/ThinkerYzu/foxmcp/blob/cc97d6ae90a9cd2a7bdeb9e38feaf9d29c395921/extension/background.js#L476-L489)).
