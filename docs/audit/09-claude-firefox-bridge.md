- Summary: A Manifest V2 Firefox add-on (Claude MCP Connect) plus a dependency-free Node.js MCP server (plugin/server/bridge.js) that Claude runs over stdio. The server and the add-on talk over a WebSocket on 127.0.0.1 with a challenge-response login that uses the user's connection code. The bridge exposes 18 MCP tools; the add-on runs them in the background page and in an on-demand content script on the top frame only, with a popup on/off switch and a per-action log.

## Architecture

- Hop 1, Claude to bridge: MCP over stdio, newline-delimited JSON-RPC, read in a loop ([bridge.js#L1083-L1113](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/plugin/server/bridge.js#L1083-L1113)). The plugin and desktop extension both start `node server/bridge.js` ([plugin.json#L42-L53](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/plugin/.claude-plugin/plugin.json#L42-L53), [manifest.json#L13-L26](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/mcpb/manifest.json#L13-L26)). Supported protocol versions are 2025-11-25, 2025-06-18, 2025-03-26 and 2024-11-05 ([bridge.js#L1037](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/plugin/server/bridge.js#L1037)). Only the tools capability is advertised ([bridge.js#L1059-L1064](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/plugin/server/bridge.js#L1059-L1064)).
- Hop 2, bridge to add-on: a hand-written RFC 6455 WebSocket server and client ([bridge.js#L105-L170](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/plugin/server/bridge.js#L105-L170), [bridge.js#L264-L299](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/plugin/server/bridge.js#L264-L299)) listening on 127.0.0.1 at the port from FF_BRIDGE_PORT or 8765 ([bridge.js#L27-L30](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/plugin/server/bridge.js#L27-L30), [bridge.js#L392](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/plugin/server/bridge.js#L392)). The add-on connects to ws://127.0.0.1 at its stored port ([background.js#L85-L98](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/extension/background.js#L85-L98)). Message size is capped at 64 MB after login and 8 KB before it ([bridge.js#L106-L107](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/plugin/server/bridge.js#L106-L107)).
- Primary and relay: the first bridge to bind the port is the primary and holds the add-on connection. Later copies join as relays and forward calls. If the primary exits, a relay takes over the port ([bridge.js#L301-L310](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/plugin/server/bridge.js#L301-L310), [bridge.js#L524-L569](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/plugin/server/bridge.js#L524-L569), [bridge.js#L572-L586](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/plugin/server/bridge.js#L572-L586)).
- Hop 3, add-on to page: MV2 persistent background page ([manifest.json#L24-L29](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/extension/manifest.json#L24-L29)). - Local folder server: the same HTTP listener on 127.0.0.1 serves read-only files under /local/ when the user has enabled Local folders ([bridge.js#L347-L351](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/plugin/server/bridge.js#L347-L351), [bridge.js#L620-L658](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/plugin/server/bridge.js#L620-L658)). - Browser side: MV2 with persistent background scripts. Other browser APIs used are tabs, windows, storage, captureVisibleTab, OffscreenCanvas and createImageBitmap ([background.js#L327-L345](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/extension/background.js#L327-L345)). The code uses the browser namespace. No native messaging is used; pairing is by the typed connection code.
- Claude or LLM sidebar: none. The UI is a toolbar popup ([manifest.json#L30-L37](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/extension/manifest.json#L30-L37)), an options page ([manifest.json#L38-L41](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/extension/manifest.json#L38-L41)) and a welcome page ([welcome.js#L5-L37](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/extension/welcome.js#L5-L37)).

Platforms: win32, darwin and linux, Node.js 18 or newer ([manifest.json#L125-L134](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/mcpb/manifest.json#L125-L134)). ## Firefox implementation notes

- Manifest V2 persistent background page with browser.tabs.executeScript ([background.js#L262-L266](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/extension/background.js#L262-L266)). Whether stable Firefox 160 accepts MV2 for this add-on was not verified in this audit; the Companion must check that before choosing this structure.
- The bridge and its WebSocket server are a separate Node.js process ([bridge.js#L1083-L1113](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/plugin/server/bridge.js#L1083-L1113)). A Firefox Companion using native messaging can drop the process and the WebSocket and its HMAC login, but then the MCP server and its tool surface must be rebuilt.
- Pairing is by a typed or pasted connection code, not native messaging (no nativeMessaging permission, [manifest.json#L17-L23](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/extension/manifest.json#L17-L23)). A Companion can replace this with native messaging, which Firefox supports in stable builds.
- captureVisibleTab and createImageBitmap on OffscreenCanvas in the background page ([background.js#L327-L345](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/extension/background.js#L327-L345)) are standard WebExtension calls. The screenshot tool activates the tab first ([background.js#L329-L332](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/extension/background.js#L329-L332)), which a no-focus-steal Companion would have to change.
- The content script is injected only into the top frame ([background.js#L271](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/extension/background.js#L271), [background.js#L334](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/extension/background.js#L334)). Iframe content is outside the design.
- No Chrome-only API was seen. The add-on relies on the Firefox promise-based browser namespace.
- Privileged-page checks are the add-on's own list ([background.js#L210-L218](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/extension/background.js#L210-L218)), not a Firefox permission. A Companion using a per-tab grant model will need its own equivalent, since this add-on has no per-tab or per-site grant (see the permission boundaries above).
- Signing: release Firefox accepts only signed add-ons. sign.ps1 and fetch-signed.ps1 use the AMO API for unlisted and listed signing ([sign.ps1#L24-L44](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/sign.ps1#L24-L44), [fetch-signed.ps1#L28-L38](https://github.com/thriftshoppin/claude-firefox-bridge/blob/65f7dc32b05fe09f76c2d4bc1774e68c127f3ee0/fetch-signed.ps1#L28-L38)). The Companion needs the same signing path.
