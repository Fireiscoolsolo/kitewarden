- Summary: FoxCode is an MIT-licensed Firefox MV2 WebExtension plus a Node.js MCP server (npm package foxcode-channel) that exposes three MCP tools: status, launchBrowser and evalInBrowser. The server listens on 127.0.0.1 and the extension connects with a token that is shared across the machine; evalInBrowser runs agent-supplied JavaScript in the extension background with cookie and tab access, and in page context through a content script, with no per-tab or per-site grant. The browser UI is a toolbar popup that acts as an eval console, not a sidebar or chat.

## Features

| ID | Capability | Observable behavior | Evidence | Firefox fit | Verification |
|---|---|---|---|---|---|
| 21-F01 | `evalInBrowser` MCP tool: runs agent JavaScript in the browser | The client sends code and an optional timeout. Code with a syntax error returns an isError text starting with Syntax error and never reaches the browser. ## Firefox implementation notes

- Native in a signed WebExtension: the DOM actions run through tabs.executeScript (21-F18), the page-world eval through wrappedJSObject in a content script (21-F19), cookies (21-F22), tabs (21-F21), webNavigation, storage.local for sessions (21-F10), the browser_action popup and badge (21-F14, 21-F15), and a WebSocket from a background page to 127.0.0.1 (21-F08). wrappedJSObject is a Firefox-specific API and has no Chrome equivalent.
- Needs a different implementation: the launch model (21-F03, 21-F04). The code starts a separate profile with npx web-ext and loads the source as a temporary add-on. A Companion needs a signed package installed in the user's existing signed-in profile, so the Node launcher and its process handling (21-F05, 21-F06, 21-F50) do not carry over. A WebExtension cannot spawn or signal processes, so any helper needs a native host or a different transport.
- Tab activation: navigate and screenshot make tabs active (21-F20, 21-F24). A background-only design must not do this.
- Injected code: dialog and console overrides (21-F25, 21-F26) go through tabs.executeScript. The code does not establish that they run in the page main world, so the page-world path used by api.eval (21-F19) is the one to copy.
- Per-tab grants and indicators: none exist (21-F33, 21-F34). The Companion must build them.
- Packaging: CI produces only an unsigned zip (21-F47, 21-F48). Stable Firefox needs a signed package. The signing rule is external to this repository and was not verified.
- CSP: the manifest allows 'unsafe-eval' (manifest.json line 14) and the background uses new Function (21-F01). Firefox allows this in MV2 extension pages, but a reviewer may question it. The Firefox 160 MV2 support status was not checked.
- Windows: the Node code has Windows branches (21-F49), but the Companion's Windows path needs its own test on Windows 11 and stable Firefox.
