- Summary: Claude no Navegador (browser-control-mcp) is a Firefox Manifest V2 add-on plus a Node.js stdio MCP server. The server exposes 20 tools and forwards each call as a signed JSON message over a localhost WebSocket to the add-on, which acts only in tabs that Claude itself opened in a tab group named "Claude". The person can pause it, switch individual tools off, block domains, approve domains one by one, and read a 100-entry audit log in the add-on's options page.

## Architecture

- Client to server: MCP over stdio only. The server uses StdioServerTransport and exits when stdin closes ([server.ts#L410-L420](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/mcp-server/server.ts#L410-L420)). There is no HTTP transport in the code.
- Server to add-on: a WebSocket server created with the `ws` package on each of the ports 8089 to 8093 that is free, the first free one being used ([browser-api.ts#L15-L17](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/mcp-server/browser-api.ts#L15-L17), [browser-api.ts#L52-L83](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/mcp-server/browser-api.ts#L52-L83)). It binds 127.0.0.1 and ::1 together, or 0.0.0.0 when the CONTAINERIZED environment variable is set ([browser-api.ts#L91-L102](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/mcp-server/browser-api.ts#L91-L102)). EXTENSION_PORT pins a single port ([browser-api.ts#L344-L345](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/mcp-server/browser-api.ts#L344-L345)).
- Add-on to server: one WebSocket per configured port, opened to ws://localhost:port, with a two-second reconnect timer ([client.ts#L23-L26](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/client.ts#L23-L26), [client.ts#L78-L93](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/client.ts#L78-L93)). The default port list is 8089 to 8093 ([extension-config.ts#L7-L9](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/extension-config.ts#L7-L9)), and background.ts starts one client per port ([background.ts#L49-L69](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/background.ts#L49-L69)).
- Message format: every message is `{payload, signature}`, where the signature is an HMAC-SHA256 of the JSON payload with the shared secret ([browser-api.ts#L268-L295](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/mcp-server/browser-api.ts#L268-L295), [auth.ts#L7-L34](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/auth.ts#L7-L34)).
- Browser side: Manifest V2 with background scripts ([manifest.json#L17-L21](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/manifest.json#L17-L21)); a toolbar popup ([manifest.json#L22-L26](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/manifest.json#L22-L26)) and an options page ([manifest.json#L27-L29](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/manifest.json#L27-L29)). Page code runs in a content script that is injected with executeScript only into tabs that Claude uses ([message-handler.ts#L413-L417](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/message-handler.ts#L413-L417)); the manifest declares no content_scripts.

There is no sidebar_action ([manifest.json#L1-L47](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/manifest.json#L1-L47)).

## Permission boundaries

- Manifest permissions: tabs, tabGroups, history, storage, webRequest and <all_urls> ([manifest.json#L6-L13](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/manifest.json#L6-L13)). activeTab is not requested.
- Host permissions: <all_urls>, the only host pattern in the manifest ([manifest.json#L12](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/manifest.json#L12)). The optional permission "find" is requested only when find-highlight is used ([manifest.json#L14-L16](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/manifest.json#L14-L16), [message-handler.ts#L221-L236](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/message-handler.ts#L221-L236)). The data-collection declaration lists websiteContent and browsingActivity as required ([manifest.json#L34-L38](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/manifest.json#L34-L38)).
- Per-tab or per-site grant: two gates are enforced in code. First, a tab must be in the Claude group: the add-on keeps the ids of tabs it opened in storage.session and refuses any other tab id ([abas-claude.ts#L10-L16](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/abas-claude.ts#L10-L16), [abas-claude.ts#L58-L64](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/abas-claude.ts#L58-L64), [message-handler.ts#L238-L244](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/message-handler.ts#L238-L244)). Second, a site must pass the authorization mode. In "perguntar" mode, which is the default, the first action on a new domain opens the options page for approval and fails with an error ([message-handler.ts#L170-L183](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/message-handler.ts#L170-L183), [extension-config.ts#L125-L132](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/extension-config.ts#L125-L132), [extension-config.ts#L388-L397](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/extension-config.ts#L388-L397)). In "autonomo" mode every site except the deny list is allowed ([message-handler.ts#L175](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/message-handler.ts#L175)). Approval matches the domain and its subdomains ([regras.ts#L107-L118](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/regras.ts#L107-L118)). Per-tab consent for screenshots, which the README describes, is not enforced: the only check is group membership ([message-handler.ts#L327-L334](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/message-handler.ts#L327-L334)).
- Authentication: the server and the add-on share EXTENSION_SECRET. Both sides sign every message with HMAC-SHA256 over the JSON payload and reject a bad signature ([browser-api.ts#L110-L127](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/mcp-server/browser-api.ts#L110-L127), [client.ts#L42-L64](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/client.ts#L42-L64)). The WebSocket handshake accepts only an Origin that starts with moz-extension:// ([browser-api.ts#L25-L32](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/mcp-server/browser-api.ts#L25-L32), [browser-api.ts#L97-L101](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/mcp-server/browser-api.ts#L97-L101)). That header is set by browsers, so it blocks web pages; a local program can send any header, so a local program can connect but without the secret it cannot get a signed command accepted. The secret is kept in the MCP client configuration as a sensitive value ([manifest.json#L37-L44](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/mcp-server/manifest.json#L37-L44)) and in the add-on's storage.local under config ([extension-config.ts#L164-L172](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/extension-config.ts#L164-L172)). The options page shows the secret and a ready-to-paste command ([options.ts#L54-L79](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/options.ts#L54-L79)).
- Sensitive-action gating: pause refuses every new command, and the pause button on the page only sets the flag through the add-on's own sender check ([message-handler.ts#L35-L42](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/message-handler.ts#L35-L42), [background.ts#L44-L47](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/background.ts#L44-L47), [agente-pagina.ts#L107-L112](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/agente-pagina.ts#L107-L112)). Each tool can be switched off ([extension-config.ts#L231-L238](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/extension-config.ts#L231-L238)). The deny list applies in every mode ([message-handler.ts#L170-L174](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/message-handler.ts#L170-L174)). File upload is off, asks per file, or is allowed, according to the setting ([message-handler.ts#L492-L501](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/message-handler.ts#L492-L501), [extension-config.ts#L419-L421](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/extension-config.ts#L419-L421)), and files with hidden path parts, key-like names, non-files and files over 25 MB are refused on the server ([arquivos.ts#L15-L24](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/mcp-server/arquivos.ts#L15-L24), [arquivos.ts#L53-L63](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/mcp-server/arquivos.ts#L53-L63), [arquivos.ts#L83-L85](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/mcp-server/arquivos.ts#L83-L85)). ## Firefox implementation notes

- Page-realm hooks (agente-pagina.ts console hook at lines 528-552 and file-picker hook at lines 597-631) use wrappedJSObject and exportFunction, which are Firefox-only. A stable-Kitewarden can keep them, but must restore the prototype methods after use and must re-verify them on Firefox 160.
- Tab groups use browser.tabGroups (Firefox 139 and later) and the Claude group ownership is kept in storage.session ([abas-claude.ts#L10-L16](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/abas-claude.ts#L10-L16)), which is native to Firefox.
- The find-highlight feature depends on the optional "find" permission and the browser.find API, both Firefox-specific ([message-handler.ts#L305-L320](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/message-handler.ts#L305-L320)). Keep it optional.
- Network log uses non-blocking webRequest listeners ([rede.ts#L25-L39](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/rede.ts#L25-L39)). Confirm the listener form on Manifest V2 or V3 before choosing a manifest version.
- Screenshots foreground the tab to capture it ([message-handler.ts#L360-L365](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/firefox-extension/message-handler.ts#L360-L365)). Kitewarden that must not move the person's tab needs another capture path, or must say so in the product.
- The local WebSocket design with a separate Node server and a shared secret ([browser-api.ts#L40-L61](https://github.com/g-lacerda/browser-control-mcp/blob/37fd83486d60ea37122f207b857376fdd8fd7a55/mcp-server/browser-api.ts#L40-L61)) is not a stable-Firefox WebExtension feature; Kitewarden can use a native messaging host or a different local transport, and the Origin check here relies on browsers setting the header.
- The Claude group, the per-domain approval and the audit log are plain WebExtension features (tabs, storage, options page), and can be reused as they are in principle.
