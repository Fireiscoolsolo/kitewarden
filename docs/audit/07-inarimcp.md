- Summary: A Firefox MV2 WebExtension (Inari MCP for Firefox, add-on id inari-mcp@elys0912.github.io) plus a Node.js native messaging host and a shared local daemon, exposed to an MCP client as 17 fox_* tools over stdio. The daemon runs a safety guard and a per-call human approval (MCP elicitation or the toolbar popup), then forwards each action over a mutually authenticated WebSocket and Native Messaging to the extension, which acts on the user's own Firefox tabs through content scripts. A Playwright-driven headless backend is also present.

## Firefox implementation notes

- Native on stable Firefox, signed WebExtension, existing profile: the tabs, tabs.captureTab, find, webNavigation, contextualIdentities, cookies (only cookieStoreId, no cookie reads), notifications, storage and contextMenus APIs, the content-script page hooks that use wrappedJSObject and exportFunction (Firefox-only), and the add-on's own popup and consent page. Features 07-F01, 07-F03 through 07-F13, 07-F15 through 07-F17, 07-F19, 07-F21, 07-F22, 07-F23, 07-F24, 07-F25, 07-F26, 07-F35 and 07-F37 work on this basis.
- Native messaging host and daemon: the Node native host, the shared daemon, the relay and the installer are outside the add-on. Any stable-Firefox companion needs its own host with a manifest registered for the add-on id, which is the adapt set (07-F20, 07-F27, 07-F28, 07-F30, 07-F32, 07-F33, 07-F34).
- Windows job-object escape (07-F29) exists only because the host process lives inside Firefox's job; a companion that avoids Native Messaging, or whose host is started by the user, does not need it.
- Headless mode (07-F36) uses Playwright's own Firefox with a disposable profile; it is not the user's Firefox and cannot share its sessions.
- Dialogs (07-F14): a WebExtension cannot answer native alert, confirm or prompt dialogs, so fox_handle_dialog has no extension equivalent here.
- Snapshot (07-F02): the accessibility snapshot exists only in headless mode; an extension version would need a new content-script walk.
- There is no CDP, Marionette, WebDriver BiDi or Chrome-only API in the extension path. The Firefox-only wrappedJSObject and exportFunction calls are the only browser-specific page-world code.
