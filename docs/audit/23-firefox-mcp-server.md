- Summary: A Node.js MCP server (stdio) that opens a WebSocket server on 127.0.0.1:9009 and waits for a Firefox MV2 WebExtension ("Browser MCP Bridge") that the user arms on one tab from the toolbar. The server exposes 13 browser_* tools that navigate the armed tab, capture an accessibility-style snapshot, click, hover, type, select, drag, press keys, wait, read console logs and take a screenshot. It does not use WebDriver, BiDi, Marionette or CDP.

## Firefox implementation notes

- Manifest version 2 with a persistent background page ([manifest.json#L2](https://github.com/nullthrix/firefox-mcp-server/blob/f678ce9c11f2d9eb02b2c4f56a86c948558b127f/extension/manifest.json#L2) [manifest.json#L26-L27](https://github.com/nullthrix/firefox-mcp-server/blob/f678ce9c11f2d9eb02b2c4f56a86c948558b127f/extension/manifest.json#L26-L27)). The manifest sets strict_min_version 140 ([manifest.json#L9](https://github.com/nullthrix/firefox-mcp-server/blob/f678ce9c11f2d9eb02b2c4f56a86c948558b127f/extension/manifest.json#L9)), not the Firefox 160 target. Whether stable Firefox 160 accepts this manifest was not checked here.
- Native APIs used: tabs, browserAction, tabs.executeScript, tabs.sendMessage, tabs.captureTab (13-F01, 13-F03, 13-F12). captureTab needs the tabs or activeTab permission ([manifest.json#L19-L20](https://github.com/nullthrix/firefox-mcp-server/blob/f678ce9c11f2d9eb02b2c4f56a86c948558b127f/extension/manifest.json#L19-L20)).
- The WebSocket to 127.0.0.1 depends on the CSP connect-src ([manifest.json#L58](https://github.com/nullthrix/firefox-mcp-server/blob/f678ce9c11f2d9eb02b2c4f56a86c948558b127f/extension/manifest.json#L58)); this is native and needs no change.
- The content script uses Firefox-only content APIs (wrappedJSObject and exportFunction, [content.js#L72-L77](https://github.com/nullthrix/firefox-mcp-server/blob/f678ce9c11f2d9eb02b2c4f56a86c948558b127f/extension/content.js#L72-L77)) to hook page console calls. These are available to Firefox content scripts.
- Trusted input is the gap: click, hover, type, select, drag and press use synthetic DOM events (13-F05 and 23-F05 to 23-F09 in this file). A Firefox-native design that needs trusted input would need another input path; the repository has none.
- The content script injects into every tab ([manifest.json#L46-L56](https://github.com/nullthrix/firefox-mcp-server/blob/f678ce9c11f2d9eb02b2c4f56a86c948558b127f/extension/manifest.json#L46-L56)). A Firefox-native design that grants access per tab would need activeTab-based injection on the user's click instead.
- Stable Firefox loads only signed add-ons (23-F17). The manifest id is browser-mcp-bridge@localhost ([manifest.json#L8](https://github.com/nullthrix/firefox-mcp-server/blob/f678ce9c11f2d9eb02b2c4f56a86c948558b127f/extension/manifest.json#L8)); signing is performed by AMO, not by this repository.
