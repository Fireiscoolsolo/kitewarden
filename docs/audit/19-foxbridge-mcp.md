- Summary: FoxBridge is a Node and TypeScript MCP server plus a Manifest V2 Firefox extension. The extension connects to the server on 127.0.0.1 port 8787 and runs tab, DOM, cookie, storage, network and download commands inside the user's running, logged-in Firefox. The server also reads the on-disk Firefox profile (cookies, history, bookmarks, sessions, localStorage) and can start a separate Playwright-controlled Firefox seeded with copies of those cookies. It registers 52 MCP tools.

## Firefox implementation notes

- Manifest V2 with a persistent background script ([manifest.json#L2](https://github.com/sinamohsenifar/foxbridge-mcp/blob/b46603599a437f4918eae0256fecb78ab2576141/extension/manifest.json#L2), [manifest.json#L22-L27](https://github.com/sinamohsenifar/foxbridge-mcp/blob/b46603599a437f4918eae0256fecb78ab2576141/extension/manifest.json#L22-L27)). Whether stable Firefox 160 still accepts this MV2 setup was not verified in this audit. The minimum declared version is 115.0 ([manifest.json#L31](https://github.com/sinamohsenifar/foxbridge-mcp/blob/b46603599a437f4918eae0256fecb78ab2576141/extension/manifest.json#L31)).
- Native WebExtension APIs used: tabs (including executeScript with code strings), cookies with httpOnly, downloads, webRequest in non-blocking form ([background.js#L112-L123](https://github.com/sinamohsenifar/foxbridge-mcp/blob/b46603599a437f4918eae0256fecb78ab2576141/extension/background.js#L112-L123)), windows and runtime. The manifest does not request nativeMessaging ([manifest.json#L13-L21](https://github.com/sinamohsenifar/foxbridge-mcp/blob/b46603599a437f4918eae0256fecb78ab2576141/extension/manifest.json#L13-L21)).
- Needs a different implementation on stable Firefox: the Playwright live-browser tools (rows 19-F16 to 19-F20) drive a separate Firefox build, not the user's running profile ([driver.ts#L44-L47](https://github.com/sinamohsenifar/foxbridge-mcp/blob/b46603599a437f4918eae0256fecb78ab2576141/src/driver.ts#L44-L47)). The bridge tools (rows 19-F02 to 19-F13) are the path that works on the user's stable Firefox.
- Disk-profile reads (rows 19-F14, 19-F15, 19-F21) use Firefox's file formats (SQLite, mozLz4) from Node. They are not WebExtension features and depend on the on-disk layout.
- Signing: the release path is web-ext signing with AMO credentials ([package.json#L49-L51](https://github.com/sinamohsenifar/foxbridge-mcp/blob/b46603599a437f4918eae0256fecb78ab2576141/package.json#L49-L51)). Unsigned XPIs are not installable on release Firefox; the repository does not contain an alternative install route.
