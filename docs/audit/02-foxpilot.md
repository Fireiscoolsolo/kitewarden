- Summary: FoxPilot is an MCP server (TypeScript on Node 22 or later, stdio to the MCP client) that exposes 46 MCP tools and drives Firefox (MV2) or Chrome/Edge (MV3) through a local broker over loopback WebSockets. An opt-in remote link relays end-to-end encrypted sessions through a relay the user deploys, and an opt-in native input sidecar sends OS-level pointer and keyboard input. The repository holds the server, both extensions, the broker, a relay worker, a feedback worker, an input sidecar and test fixtures.
