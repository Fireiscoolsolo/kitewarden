- Summary: Claude Code Bridge for Firefox is a Firefox MV2 WebExtension plus a Node 20+ MCP server. Claude Code starts `claude-firefox mcp`, which talks over a local Unix socket (macOS/Linux) or named pipe (Windows) to a native-messaging host that Firefox launches. The add-on drives tabs it owns through 14 MCP tools (13 executed in the add-on, `browser_batch` run by the MCP server). Each Claude session gets its own Firefox window, or on Zen a tab group, and Claude can act only on tabs in that window or group.

## Architecture

Hop by hop:
1. MCP client to the bridge: stdio, started by the client (`claude-firefox mcp`). No authentication; the MCP server runs with the client's privileges ([mcp-server.js#L196-L200](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/mcp-server.js#L196-L200), [cli.js#L11-L15](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/cli.js#L11-L15)).
2. MCP server to native host, macOS and Linux: Unix domain socket at `run/bridge.sock` inside the app directory ([paths.js#L18-L23](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/paths.js#L18-L23), [paths.js#L36-L39](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/paths.js#L36-L39)). The MCP server checks that the socket directory is a non-symlink, owned by the current user and not accessible to others ([mcp-server.js#L84-L90](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/mcp-server.js#L84-L90), [paths.js#L67-L72](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/paths.js#L67-L72)). The native host creates the directory with mode 0700 and chmods the socket to 0600 after listening ([paths.js#L60-L65](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/paths.js#L60-L65), [native-host.js#L55](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/native-host.js#L55)). No key is used on these platforms ([paths.js#L56-L58](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/paths.js#L56-L58)).
3. MCP server to native host, Windows: named pipe `\\.\pipe\claude-firefox-bridge-<32 hex>` read from `pipe-name` ([paths.js#L15](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/paths.js#L15), [paths.js#L51-L54](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/paths.js#L51-L54)). The MCP server sends a random nonce; the host answers with an HMAC-SHA256 of it under the 64-hex key in `pipe-key`, and the client refuses the connection unless the proof matches in constant time ([mcp-server.js#L113-L123](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/mcp-server.js#L113-L123), [framing.js#L56](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/framing.js#L56), [native-host.js#L27-L29](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/native-host.js#L27-L29)). The client does not send the key.
4. Native host to Firefox: native messaging over stdio with a 4-byte little-endian length prefix. Messages over about 900 KB are split into parts ([framing.js#L3-L15](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/framing.js#L3-L15), [framing.js#L45-L54](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/framing.js#L45-L54)). The host is launched by a wrapper written by the installer; on Windows this is a `.cmd` file, on macOS and Linux a `/bin/sh` script ([install.js#L112-L123](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/install.js#L112-L123)).
5. Firefox to background page: the background page is a persistent MV2 page that connects to the native host and dispatches each `call` by tool name ([main.js#L63-L65](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/background/main.js#L63-L65), [native.js#L8-L25](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/background/native.js#L8-L25), [dispatch.js#L45-L59](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/background/dispatch.js#L45-L59)).
6. Background to content scripts: `tabs.sendMessage` / `tabs.executeScript` to every frame. Content scripts run on `<all_urls>` at document_start, in all frames, including about:blank ([manifest.json#L17-L30](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/manifest.json#L17-L30), [content.js#L3-L41](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/background/content.js#L3-L41)). The content router dispatches `module.fn` ops to `globalThis.__cf` modules ([router.js#L1-L14](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/content/router.js#L1-L14)).
7. Page world: `console-hook.js` and `dialogs.js` use `window.wrappedJSObject` and `exportFunction` to wrap the page's console and alert, confirm and prompt ([console-hook.js#L124-L150](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/content/console-hook.js#L124-L150), [dialogs.js#L32-L60](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/content/dialogs.js#L32-L60)).

Server language and SDK: JavaScript (ES modules), `@modelcontextprotocol/sdk` ^1.32.1 with the low-level `Server` class and `StdioServerTransport` ([package.json#L33-L35](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/package.json#L33-L35), [mcp-server.js#L5-L7](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/mcp-server.js#L5-L7), [mcp-server.js#L184-L185](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/mcp-server.js#L184-L185)). The server declares only the `tools` capability ([mcp-server.js#L184](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/mcp-server.js#L184)). It has no MCP prompts, resources, skills or server instructions. No `instructions` field is set.

Browser side: WebExtension MV2 ([manifest.json#L2](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/manifest.json#L2), persistent background page at [manifest.json#L16](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/manifest.json#L16)). No CDP, Marionette or WebDriver BiDi is used by the product (searched extension/ and host/src/: none). BiDi appears only in the e2e harness, which drives trusted input for tests ([harness.js#L49-L50](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/test/e2e/harness.js#L49-L50)).

Claude/LLM sidebar UI: none. The manifest has no `browser_action`, `sidebar_action`, `options_ui` or popup ([manifest.json#L1-L31](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/manifest.json#L1-L31)). The only UI is the in-page indicator (glow, cursor and Stop/Resume pill) rendered into each top frame ([indicator.js#L2](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/content/indicator.js#L2), [indicator.js#L18-L23](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/content/indicator.js#L18-L23)).

Installer and platforms: `npx @llyfn/claude-in-firefox install` (`claude-firefox` bin) copies the package into the app directory, writes the native-messaging manifest and wrapper, creates the pipe name and key on Windows, and runs `claude mcp add` ([package.json#L12-L14](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/package.json#L12-L14), [install.js#L101-L151](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/install.js#L101-L151)). Supported platforms are macOS, Linux and Windows; any other platform throws ([paths.js#L18-L23](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/paths.js#L18-L23)). The native-messaging manifest location is the Mozilla NativeMessagingHosts folder on macOS and Linux and an HKCU registry key on Windows ([paths.js#L25-L29](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/paths.js#L25-L29), [install.js#L128](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/install.js#L128)).

## Permission boundaries

No `storage`, `cookies`, `downloads`, `history` or `scripting` permission is declared. `data_collection_permissions` lists `websiteContent` and `browsingActivity` ([manifest.json#L12](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/manifest.json#L12)).
- Host permissions: `<all_urls>` only. It is used by the `permissions` list ([manifest.json#L15](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/manifest.json#L15)), by content scripts in all frames ([manifest.json#L19-L28](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/manifest.json#L19-L28)), and by the webRequest listeners ([logs.js#L89-L93](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/background/logs.js#L89-L93)).
- Per-tab or per-site grant: no per-site or per-tab user grant exists. The grant is window or group membership. A session's windows are recorded as window values, and a tab is owned when its window is one of the session's windows (and, for a grouped session, the tab is in the session's group) ([sessions.js#L25](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/background/sessions.js#L25), [sessions.js#L40](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/background/sessions.js#L40), [sessions.js#L42-L45](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/background/sessions.js#L42-L45)). Each new session opens a new unfocused window ([sessions.js#L113-L122](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/background/sessions.js#L113-L122)). On Zen, a session gets one tab group in the user's current window and owns only that group ([sessions.js#L129-L140](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/background/sessions.js#L129-L140), [sessions.js#L7](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/background/sessions.js#L7)). ## Firefox implementation notes

Features that need a different or extra implementation on stable Firefox 160 (Windows), and why:

- Synthetic input (`computer` clicks, keys, typing, scroll, drag, `isTrusted` false, see [README.md#L59-L63](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/README.md#L59-L63)): a WebExtension has no OS-level input. Trusted input would need a remote-control channel (WebDriver BiDi or Marionette), which this add-on does not use. Stable Firefox would need that channel for pages that ignore simulated events.
- Tab groups (Zen path, `tabs.group`, `tabGroups`, [sessions.js#L49-L63](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/background/sessions.js#L49-L63)): need Firefox 139 or newer ([2026-10-17-claude-in-firefox-design.md#L29](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/docs/superpowers/specs/2026-10-17-claude-in-firefox-design.md#L29)) and the `browser.tabs.groups.enabled` preference, whose message is at [sessions.js#L5](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/background/sessions.js#L5). The code does not set the pref. Confirm the default on Firefox 160 stable.
- Zen detection (`runtime.getBrowserInfo().zen`, [main.js#L18-L20](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/background/main.js#L18-L20)): Zen-only. On stable Firefox the window path is used.
- Session window values (`sessions.setWindowValue` and `getWindowValue`, [sessions.js#L40](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/background/sessions.js#L40), [sessions.js#L70-L72](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/background/sessions.js#L70-L72)): Firefox-only API used for persistence. Chromium has no equivalent.
- Page-world hooks (`wrappedJSObject`, `exportFunction`, [console-hook.js#L124-L152](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/content/console-hook.js#L124-L152), [dialogs.js#L32-L60](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/content/dialogs.js#L32-L60)): Firefox Xray and exportFunction. Works in a signed Firefox WebExtension, but the behaviour is Firefox-specific and must be retested on Firefox 160.
- MV2 persistent background page ([manifest.json#L2](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/manifest.json#L2), [manifest.json#L16](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/manifest.json#L16)), plus `tabs.executeScript`, `tabs.captureTab` and non-blocking `webRequest` ([capture.js#L19-L24](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/background/capture.js#L19-L24), [content.js#L4-L8](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/background/content.js#L4-L8), [logs.js#L89-L93](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/background/logs.js#L89-L93)): all used here. Confirm MV2 support on the target Firefox build; the repository has no plan for MV3.
- Native messaging on Windows is the HKCU registry key ([install.js#L128](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/install.js#L128)) with a `.cmd` wrapper ([install.js#L115](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/install.js#L115)). A named pipe with an HMAC challenge replaces the Unix socket ([paths.js#L51-L54](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/paths.js#L51-L54)). A stable-Firefox build needs the same manifest location.
- Profile handling: one profile at a time, enforced by the native host's bind ([native-host.js#L51-L54](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/host/src/native-host.js#L51-L54)). Multi-profile use needs a per-profile socket or pipe name.
- Unsigned or stable-release installs: the add-on is listed on addons.mozilla.org through the release workflow ([release.yml#L38-L44](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/.github/workflows/release.yml#L38-L44)). A developer build needs Developer Edition or Nightly with signatures disabled ([CONTRIBUTING.md#L17](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/CONTRIBUTING.md#L17)).
- Restricted pages: about:, addons.mozilla.org and other Firefox-reserved pages cannot run the content scripts ([content.js#L19-L21](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/extension/background/content.js#L19-L21), [README.md#L55](https://github.com/llyfn/claude-in-firefox/blob/989e483d3514c4ff407584cd8952e580af617c1d/README.md#L55)). The same limit applies on stable Firefox.
