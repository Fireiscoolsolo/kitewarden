- Summary: Agent F is a Firefox MV2 WebExtension (manifest version 0.5.2) plus a Python 3.11+ MCP broker and a standard-library native-messaging helper. The broker serves 41 MCP tools over Streamable HTTP on 127.0.0.1 with a bearer token. It acts in the user's running profiles, including their logins, mostly in background tabs grouped as "Agent F". Access is not limited per tab or per site: every tab in every connected profile is visible and can be acted on.

## Architecture

Hop by hop:
1. MCP client to broker: Streamable HTTP at `http://127.0.0.1:47470/mcp` by default ([config.py#L10-L13](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/config.py#L10-L13), [config.py#L77-L78](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/config.py#L77-L78), [broker.py#L46-L47](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/broker.py#L46-L47)). The MCP server is FastMCP from the official Python SDK ([server.py#L5](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/server.py#L5), [server.py#L89-L91](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/server.py#L89-L91)). The ASGI app is wrapped by a Guard that checks the request (see Permission boundaries).
2. Broker to helper: plain TCP on `127.0.0.1:47471` (`bridge_port`), length-prefixed JSON frames with a big-endian length ([bridge.py#L39-L48](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/bridge.py#L39-L48), [bridge.py#L237-L239](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/bridge.py#L237-L239)). The bind host comes from config.json ([config.py#L42-L48](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/config.py#L42-L48)). The first frame must be an auth frame carrying the token, compared in constant time within 5 s ([bridge.py#L18](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/bridge.py#L18), [bridge.py#L248-L255](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/bridge.py#L248-L255)).
3. Helper to Firefox: native messaging over stdio with a native-endian 4-byte length ([agent_f_host.py#L44-L56](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/host/agent_f_host.py#L44-L56)). The helper reads the token and config from the data folder and sends the auth frame ([agent_f_host.py#L110-L122](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/host/agent_f_host.py#L110-L122)). If the broker is down, the helper starts `broker_command` and retries ([agent_f_host.py#L74-L100](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/host/agent_f_host.py#L74-L100)).
4. Background page: a persistent MV2 page ([manifest.json#L45-L56](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/manifest.json#L45-L56)) connects with `connectNative("agent_f")` and dispatches each request to a command table ([background.js#L97-L108](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/background/background.js#L97-L108), [background.js#L110-L127](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/background/background.js#L110-L127), [background.js#L229-L274](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/background/background.js#L229-L274)).
5. Background to content: `tabs.sendMessage` to a frame with `{agentF, command, params, build}`; a stale copy of the content files is reinjected ([page.js#L72-L97](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/background/page.js#L72-L97), [page.js#L57-L70](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/background/page.js#L57-L70)). The content router dispatches named handlers and returns `{ok, result}` or `{ok:false, error}` ([main.js#L12-L36](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/content/main.js#L12-L36), [main.js#L40-L59](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/content/main.js#L40-L59)).
6. Page world: content scripts wrap the page's alert, confirm, prompt and window.open, and console methods with exportFunction via `window.wrappedJSObject` ([hooks.js#L51-L100](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/content/hooks.js#L51-L100), [hooks.js#L145-L169](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/content/hooks.js#L145-L169)).
7. Optional remote control: the broker opens a WebSocket (WebDriver BiDi) to Firefox's own remote agent for trusted input, privileged page access and Firefox preferences ([webdriver.py#L36-L57](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/webdriver.py#L36-L57), [webdriver.py#L128-L147](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/webdriver.py#L128-L147), [webdriver.py#L150-L182](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/webdriver.py#L150-L182)).

Server language and SDK: Python 3.11 or later, dependencies `mcp>=1.12,<2` and `uvicorn>=0.30` ([pyproject.toml#L10-L13](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/pyproject.toml#L10-L13)). The helper uses only the standard library ([agent_f_host.py#L1-L7](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/host/agent_f_host.py#L1-L7)). The server declares instructions, which are the agent guidance text ([server.py#L13-L28](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/server.py#L13-L28), [server.py#L90](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/server.py#L90)). It registers tools only: no MCP prompts or resources are registered (searched broker/agent_f: none).

Browser side: WebExtension MV2 ([manifest.json#L2](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/manifest.json#L2)) with a persistent background page ([manifest.json#L45-L56](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/manifest.json#L45-L56)). The extension uses browser.webRequest, browser.tabs.executeScript, browser.tabs.captureTab, browser.find, browser.history, browser.bookmarks, browser.downloads, browser.sessions, browser.contextualIdentities and browser.tabGroups. No CDP or Marionette is used. WebDriver BiDi is used only by the broker, through the optional remote-control path above.

Sidebar, popup and options UI: a toolbar popup ([manifest.json#L57-L70](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/manifest.json#L57-L70)) with a pause button, a status line and a list of the last 20 actions ([panel.js#L54-L122](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/ui/panel.js#L54-L122), [background.js#L18-L39](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/background/background.js#L18-L39)). An options page ([manifest.json#L71-L73](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/manifest.json#L71-L73)) sets the profile label and the default confirm answer ([options.js#L13-L33](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/ui/options.js#L13-L33), [options.html#L11-L33](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/ui/options.html#L11-L33)). There is no sidebar_action and no chat UI ([manifest.json#L1-L91](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/manifest.json#L1-L91)).

## Permission boundaries

- Manifest permissions: `tabs`, `tabGroups`, `contextualIdentities`, `cookies`, `nativeMessaging`, `storage`, `webNavigation`, `webRequest`, `webRequestBlocking`, `find`, `history`, `bookmarks`, `downloads`, `sessions`, `<all_urls>` ([manifest.json#L28-L44](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/manifest.json#L28-L44)).
- Host permissions: `<all_urls>` only, in the permissions list ([manifest.json#L43](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/manifest.json#L43)). Content scripts run in all frames on `<all_urls>`, including about:blank, at document_start ([manifest.json#L74-L90](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/manifest.json#L74-L90)). Restricted pages are reached by Firefox's own rules ([README.md#L74](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/README.md#L74) says so).
- Per-tab or per-site grant: none enforced. The broker and the add-on act on any tab id that the agent learns from list_tabs, in any normal window of any connected profile ([background.js#L148-L187](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/background/background.js#L148-L187), [tabs.js#L266-L282](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/background/tabs.js#L266-L282), [tabs.js#L326-L331](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/background/tabs.js#L326-L331)). The user's own tab is the default target when no tab is given: the broker resolves the focused window's active tab ([toolkit.py#L170-L176](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/toolkit.py#L170-L176), [tabs.js#L221-L231](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/background/tabs.js#L221-L231)). `navigate` is the only tool that refuses that fallback ([tools.py#L257](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/tools.py#L257), [tools.py#L267-L269](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/tools.py#L267-L269)). A new Agent F tab is put in an orange tab group named "Agent F" ([common.js#L7-L8](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/background/common.js#L7-L8), [tabs.js#L166-L172](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/background/tabs.js#L166-L172)).
- Authentication: client to broker: the Guard rejects any request that has an Origin header with 403, rejects a Host header other than 127.0.0.1 or localhost on the MCP port with 403, and requires `Authorization: Bearer <token>` with a constant-time compare (401) ([server.py#L31-L48](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/server.py#L31-L48)). Token: 32 random bytes as hex, written once to `token` in the data folder, chmod 0600 on POSIX only ([config.py#L57-L74](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/config.py#L57-L74)). Broker to helper: the token in the first frame, as above ([bridge.py#L248-L255](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/bridge.py#L248-L255)). The token is sent unencrypted over loopback TCP. Helper to add-on: Firefox native messaging, with `allowed_extensions` set to the add-on id in the native manifest ([platforms.py#L43-L50](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/install/platforms.py#L43-L50), [install.py#L155-L162](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/install/install.py#L155-L162)). The add-on accepts any request from its native port without a token ([background.js#L110-L127](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/background/background.js#L110-L127)). Bind address: the broker binds the host from config.json, which defaults to 127.0.0.1 and is not validated ([config.py#L29-L35](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/config.py#L29-L35), [broker.py#L37-L47](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/broker.py#L37-L47)). WebDriver: the broker connects to each endpoint listed in a WebDriverBiDiServer.json under the Firefox profiles, and to 127.0.0.1:9222 when none is listed, with no authentication ([webdriver.py#L128-L147](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/webdriver.py#L128-L147), [webdriver.py#L165](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/webdriver.py#L165)). Cursor's MCP file receives the bearer token in plaintext for clone installs ([install.py#L202-L219](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/install/install.py#L202-L219), [install.py#L342-L343](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/install/install.py#L342-L343)).
- Sensitive-action gating: no confirmation prompt, deny list or per-site check exists anywhere. The tool texts ask the model to ask the user (for example before closing tabs or before changing preferences) but nothing enforces it ([tools.py#L173](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/tools.py#L173), [tools_webdriver.py#L266](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/tools_webdriver.py#L266), [tools_webdriver.py#L202-L204](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/tools_webdriver.py#L202-L204)). ## Firefox implementation notes

Features that need a different implementation on stable Firefox 160 (Windows), and why:

- Remote control (`eval_browser`, `get_prefs`, `set_prefs`, and the trusted paths in `click`, `type`, `press_key`, `hover`): the broker connects to a WebDriver BiDi endpoint that Firefox exposes only under remote control. The README says that is Nightly only ([README.md#L31](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/README.md#L31)), and the pref it names is Nightly-only ([webdriver.py#L20-L23](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/webdriver.py#L20-L23)). Stable Firefox needs another route, or these tools stay unavailable. The fallback on port 9222 ([webdriver.py#L146](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/webdriver.py#L146)) would also need review.
- Page-world hooks (dialogs, window.open, console): exportFunction and wrappedJSObject are Firefox-only ([hooks.js#L51-L100](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/content/hooks.js#L51-L100), [hooks.js#L145-L169](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/content/hooks.js#L145-L169)). They work in a signed Firefox add-on but do not port to Chromium.
- Firefox-only APIs: contextualIdentities (containers), find ([page.js#L457-L473](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/background/page.js#L457-L473)), filterResponseData and requestBody in webRequest ([capture.js#L133-L157](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/background/capture.js#L133-L157)), and the sessions restore and recently-closed calls ([data.js#L105-L136](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/background/data.js#L105-L136)).
- Tab groups: tabs.group and tabGroups ([tabs.js#L122-L133](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/background/tabs.js#L122-L133)). Stable Firefox 140 or later has them; the Agent F group title and colour are set through tabGroups.update.
- Synthetic input only without remote control: clicks, keys and drags carry isTrusted false, so pages that check trust ignore them (the tool text says so at [tools.py#L456-L458](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/broker/agent_f/tools.py#L456-L458)).
- Native messaging on Windows: HKCU key and a .bat launcher that waits out an install ([platforms.py#L106-L123](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/install/platforms.py#L106-L123)). The same manifest path has to be used on stable Firefox.
- MV2 persistent background page ([manifest.json#L45-L56](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/manifest.json#L45-L56)): used throughout; check MV2 support on the target build. SPEC says MV2 is deliberate ([SPEC.md#L41](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/SPEC.md#L41)).
- Add-on install by copying the .xpi into the profile's extensions folder ([install.py#L304-L308](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/install/install.py#L304-L308)): depends on Firefox accepting an extension file dropped into a profile, and on signing. Not verified on stable Firefox 160.
- Profile restrictions: the add-on cannot run on about: pages, view-source, or Mozilla's restricted domains ([page.js#L57-L70](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/extension/background/page.js#L57-L70) error text, and [README.md#L74](https://github.com/drubino-mozilla/agent-f/blob/9e87e4bec424da3e782fe850e5fed292813aeb12/README.md#L74)). The same applies to stable Firefox.
